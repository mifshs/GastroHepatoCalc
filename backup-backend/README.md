# Резервная копия защищенного бэкенда (Hardened Backend)

В этой папке сохранен полноценный изолированный Node.js-бэкенд с защитой авторских формул диссертации.

## Что входит в эту резервную копию:
1. **server.js**:
   - Полная изоляция запатентованных формул литолиза ЖКБ и регресса стеатоза печени (клиентский браузер не видит математические веса и формулы).
   - Защита от DoS/DDoS (Slowloris, ClientError, Race Condition, Uncaught Exceptions).
   - Встроенный Rate Limiter (защита от флуда запросов: 30 расчетов/мин на IP).
   - Сессионная аутентификация администратора с криптографическими токенами.
   - Безопасная отдача статических файлов с защитой от Path Traversal и строгими HTTP-заголовками безопасности (CSP, X-Frame-Options, HSTS).
2. **app.js**:
   - Клиентская часть, настроенная на обязательное обращение к защищенному API `/api/calc/litoliz` и `/api/calc/steatoz`.
3. **package.json**:
   - Конфигурация запуска Node.js (`npm start`).

## Как развернуть на российском сервере (Timeweb Cloud / Beget / VPS):
Если вы решите вернуть формулы на отдельный закрытый сервер:
1. Арендуйте микро-сервер с Ubuntu / Debian (от 150-190 ₽/мес).
2. Установите Node.js 18+:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```
3. Скопируйте файлы проекта в рабочую папку на сервере (например, `/var/www/gastro`).
4. Запустите через менеджер процессов PM2 (для непрерывной работы 24/7):
   ```bash
   sudo npm install -g pm2
   pm2 start server.js --name "gastro-calc"
   pm2 startup
   pm2 save
   ```
5. Настройте Nginx или привяжите домен (с бесплатным SSL от Certbot / Let's Encrypt).
